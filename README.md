# Angular ile Web Uygulama Geliştirme Eğitimi

Angular, Google tarafından geliştirilen ve kurumsal projelerde yaygın olarak kullanılan güçlü bir frontend framework’tür.

Bu bootcamp içerisinde TypeScript kullanarak modern, ölçeklenebilir ve sürdürülebilir web uygulamaları geliştirme süreçleri öğretilmektedir.

Katılımcılar gerçek proje mantığı ile:

- Angular component mimarisi
- TypeScript
- SPA mimarisi
- Routing
- Service ve Dependency Injection
- RxJS
- REST API entegrasyonu
- Reactive Forms
- Angular Material
- State management
- Kurumsal frontend proje yapısı

konularında uygulamalı çalışma yapar.
